## char → int

```cpp
cout << (c - 'a');

// prints 2 if c = 'c'
```

`'c' (99) - 'a' (97) = 2`

## char → int (digits)

```cpp
cout << (c - '0');

// prints 5 if c = '5'
```

`'5' (53) - '0' (48) = 5`

---

## int → char (alphabet)

```cpp
cout << ('a' + 2);

// prints 'c'
```

## int → char (digits)

```cpp
cout << ('0' + 5);

// prints '5'
```

---

### Key idea

- `'a'` ↔ alphabet mapping
- `'0'` ↔ digit mapping
