### Problem

The key idea is that every adjacent pair must have the same sum.

Examples of good & !good arrays

1. `[1, 2, 1, 2]`

Adjacent sums:

`1 + 2 = 3`

`2 + 1 = 3`

`1 + 2 = 3`

So this is `good`, with k = 3.

2. `[2, 5, 2, 4]`

`2 + 5 = 7`

`5 + 2 = 7`

`2 + 4 = 6`

Not all equal → `not good`.

### Solution

Let the no. of elements be `n`,

The condition is essentially:

- There must be at most 2 distinct values.
- For n even: both values must occur `n/2 times`.
- For n odd: one value occurs `n/2 + 1` times and the other `n/2` times.

```cpp
void solve()
{
    // ================inputs==============
    int n; // size of the array
    cin >> n;
    // ====================================

    unordered_map<int, int> freq;

    for (int i = 0; i < n; ++i)
    {
        int x;
        cin >> x;
        freq[x]++;
    }

    // more than 2 distinct values
    if (freq.size() > 2)
    {
        cout << "NO\n";
        return;
    }

    // only one number
    if (freq.size() == 1)
    {
        cout << "YES\n";
        return;
    }

    // exactly 2 differnt numbers
    int f1 = 0, f2 = 0;

    /*
    for (auto p : freq): Iterates over each key-value pair in the map, where p.first is the number and p.second is its frequency.

        if (f1 == 0) => f1 = p.second;
    On the first iteration, f1 is 0, so it assigns the count of the first distinct number to f1.

        else f2 = p.second;
    On the second iteration, f1 is no longer 0, so it assigns the count of the second distinct number to f2.
    */

    for (auto p : freq)
    {
        if (f1 == 0)
            f1 = p.second;
        else
            f2 = p.second;
    }

    /*
    This snippet checks whether the two numbers can be arranged in an alternating pattern:

    When n is even: Both numbers must appear exactly the same number of times (n/2 each).
    When n is odd: One number must appear exactly once more than the other (n/2 + 1 vs n/2).


    Why abs(f1 - f2) <= 1 works:
    It combines both rules into a single check:
        1. |f₁ - f₂| = 0 means both elements have equal frequencies (valid for even n).

        2. |f₁ - f₂| = 1 means one element appears once more than the other (valid for odd n).

        3. |f₁ - f₂| > 1 means it is impossible to alternate the numbers without having two identical numbers adjacent to each other, breaking the uniform pair-sum rule.
    */

    if (abs(f1 - f2) <= 1)
        cout << "YES\n";
    else
        cout << "NO\n";
}``
```
