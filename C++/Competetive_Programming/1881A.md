### ALGO:

- Check whether longstr is already inside shortstr.
- If not, double shortstr.
- Check again.
- Keep doing this until the string is definitely long enough.
- If it never appears, return -1.

```cpp
    while (t--) {
        int length_short, length_long;
        cin >> length_short >> length_long;

        string shortstr;
        string longstr;

        cin >> shortstr >> longstr;

        int operations = 0;
        bool found = false;

        // Try the original string and successive doublings.
        for (int i = 0; i <= 6; i++) {
            if (shortstr.find(longstr) != string::npos) {
                found = true;
                break;
            }

            // Double x for the next operation.
            shortstr += shortstr;
            operations++;
        }

        cout << (found ? operations : -1) << '\n';
    }
```
